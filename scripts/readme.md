# Scripts

This directory contains scripts used throughout this home lab. Can be used in PowerShell

## 📁 Files Overview

*   **`createusers&changepasswordnextlogon.txt`** — A script automated to handle user creation and add to a specific OU (if necessary) - Enforces a password update on their next login
*   **`readme.md`** — This documentation file.
*   **`scripttocreateusers.txt`** — A script used to create users and add to a specific OU (if necessary) - Password is permanent and does not change at next login

## 🚀 How to Use

> [!NOTE]
> Review the contents of each script and adjust any environment variables, domain names, or placeholder parameters before execution.

1. Open a PowerShell terminal
2. Copy and paste script into PowerShell and run it
3. Users should show up in Active Directory once the script completes
