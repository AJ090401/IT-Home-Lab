# IT Home Lab

A collection of virtual IT labs I built to develop hands-on experience with Windows Server, Active Directory, DNS, networking, and system administration. A little bit of Linux will be involved

**Click the readme.md file under each OS system folder for more information on tasks completed for each operating system!**

## Labs

- Active Directory / Domain Controller (Avengers.local)
- DHCP
- Windows Client/Server Administration
- OUs and Security Groups
- GPO
- DNS 
- File Shares 
- Firewalls (TBD)
- Scripts with AD/PowerShell 
- Linux Mint Practice Activities (TBD)
